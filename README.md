Projset: BST & AVL Visualizer

Open index.html in a browser to interact with the demo. Use the mode selector to switch between BST and AVL. Enter numbers and click Insert/Delete/Search to manipulate the tree. The visualization uses SVG and shows simple automatic layout.

Files:
- index.html — UI
- styles.css — styles
- script.js — BST/AVL implementation and rendering

Built by an AI assistant using Copilot CLI runtime in VS Code.
